# 四川川江科技研究院网站

「高山流水觅知音」界面 DEMO V7，首页主张“懂场景，更懂下一步”。恢复第一版墨青、米白、青绿与哑金色系，并接入宣传片中的四个真实产品标识。V7 去除标识白色托盘，以玉青核心、精细环线、玻璃卡片和交互光路精修平台连接图。公共内容采用 Astro 静态生成，反馈、智能服务与运营工作台采用 React 岛屿，样式采用 Tailwind CSS v4 与 CSS 设计令牌，交互代码使用 TypeScript。沿用 [技术栈决策](docs/技术栈决策.md)。

## 本地运行

Node.js 24 LTS、pnpm 10.20.0。

```shell
pnpm install --frozen-lockfile
pnpm dev
```

浏览器打开 http://127.0.0.1:4321 。`pnpm check` 检查类型，`pnpm build` 生成 `apps/web/dist`，`pnpm preview` 预览构建。

本机还可以双击 `start-site.cmd` 启动开发预览；它优先使用已安装的 Node/pnpm，并支持当前环境已有的本地运行时。

## 原型范围

- 十个 hash 路由：home、products、solutions、about、downloads、support、admin、assist、resources、operations。
- Canvas 实时生成的无轮廓淡墨山体、连续水线与同波场粒子；时间自驱，鼠标、滚动和可选本地麦克风音量增强，不依赖声音。
- 四款产品与四个行业场景，统一品牌、导航和页面系统。
- 构建时生成独立“川江产品界面体验包.html”，支持真实下载。正式试用软件尚未提供。
- 反馈提交、编号、历史、状态分类、搜索和回复；localStorage 在同源标签页与 React 岛屿间同步。
- 公开资料搜索、带引用的本地规则咨询、可信图示、摘要下载、需求表单及北京时间预约意向。
- 本地线索、透明完整度评分、商机跟进与结果；运营来源样例、审批/发布/索引状态演示和运行监控入口。
- 移动布局、键盘焦点和页签方向键、状态播报、减少动态效果偏好、离屏渲染暂停。

企业事实、产品名称与原始 LOGO 依据用户提供的企业文档与宣传片解说。产品工作台为界面概念，不包含实际 AI 推理；反馈只保存在当前浏览器，不发送给企业。正式上线需接入后端、登录权限与真实软件版本。

## 客户试看包

`pnpm package:preview` 构建离线入口、下载体验文件、设计导览和精选截图。离线 React 岛屿由 `scripts/preview-entry.ts` 水合，运行时、CSS、LOGO、四个产品标识与下载数据内联；完整宣传片和原片封面随“品牌素材”目录附上。交付目录为 `交付/四川川江科技研究院-界面DEMO-V7-20261015`。此前各版交付保留。功能对照见 [技术功能与界面入口](docs/技术功能与界面入口-V7.md)。
