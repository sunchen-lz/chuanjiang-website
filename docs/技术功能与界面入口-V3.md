# 技术功能与界面入口 · V3

本表逐项对照 `技术栈决策.md`。网站 DEMO 用于评审界面及入口；已选技术栈继续沿用，不把界面演示描述为已上线服务。

| 技术架构确定的功能 | 本版界面入口 | DEMO 呈现 / 上线实施 |
|---|---|---|
| 服务、行业、案例、技术问答、文档、职位 | 服务与资料、行业方案、公开资料搜索、人才与创新合作 | 实际企业资料展示；案例与职位无原始资料，明确待补充，提供交流入口 |
| 关键词与语义检索 | 顶部搜索、首页“智能搜索”、智能服务搜索页 | 本地公开资料搜索；生产需接入关键词 + 向量融合检索 |
| 限定知识范围、带引用的 AI 咨询 | 首页主 CTA、主导航“智能服务” | 本地规则回应、资料引用、资料不足提示；生产接百炼模型、检索及流式接口 |
| 需求摘要及可信架构图示 | AI 回应中的“带着摘要继续交流”、建议架构示意 | 结构化摘要、TXT 下载、受限模板图示；模型生成及 schema 校验在生产实施 |
| 需求表单、预约与 AI 故障回退 | 需求与预约 | 无需 AI 也可填写、保存本地线索、提交北京时间预约意向；未实际确认日历时段 |
| 软件试用与下载 | 下载中心 | 界面体验包实际下载；正式软件版本与适用系统待提供 |
| 用户反馈与后台处理 | 服务与支持、反馈处理台 | 本地提交、编号、分类、搜索、回复、状态同步、持久化 |
| 第一方访客来源及旅程 | 页脚“访客与来源”、运营工作台 | 标注样例的渠道、来源、访客旅程与转化；没有真实访问采集 |
| 线索评分、跟进、商机、报价与结果 | 运营工作台“线索与商机” | 读取本地需求；完整度评分显示规则；跟进、报价、成交/流失状态可保存 |
| CRM 适配与同步失败恢复 | 线索详情、运行监控任务区 | 展示连接器与异步任务入口；未连接外部 CRM，重试在生产实施 |
| CMS 内容类型、角色、审批和版本 | 运营工作台“内容与发布” | 编辑/审核/管理员角色示意，草稿→审核→发布流程；真实权限与版本由 Payload 实施 |
| CMS、页面上线、知识索引三种状态 | 发布状态面板 | 三种状态明确分开，可演示发布与撤回；生产需 Worker 和任务去重 |
| SEO、Sitemap、站长渠道及收录监测 | 服务资料、内容与发布、运行监控“搜索与渠道” | 内容字段与监测入口可见；生产需稳定公共 URL、结构化 SEO 与真实站长数据，本版 hash 路由是离线演示组织方式 |
| 性能、错误、任务、模型耗时与成本 | 运营工作台“运行监控” | 样例指标及入口；未接入 OpenTelemetry/SLS/云监控 |
| 发布、回滚、备份和恢复 | 运行监控“上线与回滚” | 流程入口规划；部署与容灾在上线阶段实施 |

## 二期预留

规则推荐、A/B 实验、结构化能力查询、文档读取和预约 API、WebMCP 适配、开放 API 文档、沙盒/密钥/用量、简历匹配与语言字段沿用原技术决策。没有对外 API、职位和服务配置时，不虚构已开放能力。本版通过服务资料、人才合作、内容模型和运营入口承接后续扩展。

## 视觉修订

恢复第一版墨青 / 米白 / 青绿 / 哑金色系，保留实际 LOGO 原色。山不绘轮廓，以模糊墨色体积和留白表达；水保留流线，粒子按同一波场流动，呈现波峰反光与聚散。时间持续驱动，鼠标、滚动和可选声音增强。
