# 四川川江科技研究院 · 界面 DEMO V2

首页主张：**懂场景，更懂下一步。** 品牌语：**川江奔涌，向新而行。**

“高山流水”提供创意基石，“知音”升华为对业务语境的理解。山是研究深度与积累，水是信息、产品和服务的持续连接，最终导向人工智能与行业应用。

## 视觉与动效

- 多层半透明墨山与留白，用艺术抽象保留东方意境。
- 27 组连续水线实时生成，包含移动亮线和速度变化，取代粒子水。
- 时间自动驱动，指针与滚动增强节奏。声音仅为可选增强，无声或授权失败也能持续流动。
- 实际 LOGO、深墨蓝、科技蓝和品牌红；首页、产品、行业、下载、支持、关于和处理台共享组件。
- 支持减少动态效果、离屏暂停和移动布局。

## 内容与路径

企业事实依据用户提供的 DOCX，产品名称、产业模式和品牌故事依据宣传片解说。首页主张、产品场景描述与工作台均是本轮设计创作，工作台标注“界面概念 DEMO”，没有声称已具备真实推理能力。

信息层级参考钉钉官网的品牌、产品、场景、下载与支持入口；不复制品牌资产或布局。

七个 hash 路由：`#/home`、`#/products`、`#/solutions`、`#/downloads`、`#/support`、`#/about`、`#/admin`。

业务展示包含工格办公、康小和、智小达、泸小智，以及政企服务、智慧医养、智慧教育、数字文化。

真实下载流程提供独立可运行的 HTML 界面体验包。正式试用软件尚未提供，产品行明确标注安装包准备中，提供试用申请入口。

反馈形成提交 → 编号 → 前台记录 → 管理处理 → 回复 → 状态同步闭环。当前使用浏览器本地数据，演示记录与实际测试记录有区分，未接入生产后台或账号权限。
