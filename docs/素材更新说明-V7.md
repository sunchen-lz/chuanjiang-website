# 素材与视觉更新 · V7

本版沿用 V1 饱和度与山水动效，针对产品标识和平台连接图进行精修。

- 四款产品使用原片透明标识，去除首页与相关页面的白色托盘。康小和单色标识在深底上采用浅玉青显示。
- 平台核心增加玉青反射、内阴影、细环刻度及局部暖金光点，产品卡片增加薄边高光与玻璃层次。
- 连线按真实布局计算端点，悬停与键盘聚焦同步点亮对应路径；各屏宽保留四个产品入口。
- 试看包、下载体验包、页面截图与设计导览同步更新。
