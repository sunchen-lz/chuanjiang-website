# 界面 DEMO V3

本版回应四项修订：恢复第一版墨青/米白/青绿/哑金；加入随波聚散的水光粒子；取消山脊硬轮廓，使用扩散墨色；按技术栈决策补齐功能界面与可见入口。

保留实际 LOGO、企业与产品资料。首页深墨色和内页暖纸色共用青绿、哑金、字体、间距、线流和导航系统。自驱水波不依赖声音；麦克风、鼠标与滚动仅增强动效。

十个路由覆盖首页、产品、行业、服务资料、智能服务、关于、下载、支持、反馈后台与运营后台。智能服务含搜索、咨询及需求预约三个视图；运营工作台含访客来源、线索商机、内容发布及运行监控四个视图。

智能咨询为本地公开资料与规则演示，含引用与受限模板图示。需求摘要可下载，预约意向及线索在本浏览器保存；可记录评分规则、跟进、报价、成交与流失状态。发布流程区分内容、页面和知识索引状态。真实模型、数据库、CMS、权限、访问采集、CRM 与监控仍按原架构上线实施。

逐项功能映射见《技术功能与界面入口-V3.md》。交付包包含可离线操作的页面、独立产品体验包、设计导览 HTML/PDF、功能对照和精选截图；前两版交付保留。
