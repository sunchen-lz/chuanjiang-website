# 四川川江科技研究院 · 高山流水觅知音

首页主张：**听见山水，也听见你。**

访客是伯牙，网站是子期。页面从“理解”开始，经过需求情境与能力介绍，最后帮助访客把模糊的想法整理成可以讨论的需求。传统意象通过实时生成的粒子、线条和声音表达，整站不使用静态山水背景图。

## 视觉语言

| 元素 | 设计表达 | 当前实现 |
| --- | --- | --- |
| 山 | 深青墨色空间里的多层粒子山势 | WebGL 顶点与片元着色器；滚动、鼠标、音量共同驱动；无 WebGL 时用 Canvas 绘制 |
| 水 | 山脚流动的细密水纹 | 解析波形 Shader，叠加鼠标涟漪和麦克风音量；属于视觉流动效果，不是物理流体求解 |
| 琴 | 导航下方的细线与 CTA 拨动反馈 | SVG 路径、CSS/WAAPI 动画与 Web Audio 合成音；声音默认关闭 |
| 知音 | 选择需求后山水颜色、光点和线条发生共鸣 | 三种预设情境的状态切换、SVG 粒子合流与首屏粒子反馈 |
| 留白 | 明暗段落交替，文字克制、重点鲜明 | 墨青 #0a1719、浅米 #e8e0cc、暖金 #d8b777、青绿 #a1ddd0 |

字体采用本地中文无衬线与等宽字体回退，无外部字体请求。所有品牌名称统一为“四川川江科技研究院”。

## 页面结构

1. **听见山水，也听见你**：动态首屏、需求 CTA、声音开关、麦克风体验。
2. **真正的智能，先从听懂开始**：用伯牙与子期的关系解释技术理念。
3. **你不必把问题说得很完整**：三种企业需求情境、对应回应与山水联动，可把方向带入需求摘要。
4. **能力图谱**：AI 语音、情感计算、企业智能、边缘计算；每项提供详情对话框及进一步讨论入口。
5. **山水有声，知音无形**：以简短文字收束品牌理念。
6. **把你的想法弹给我们听**：输入、复制或下载需求摘要。

手机端提供折叠导航、两列能力卡与垂直山水体验。支持键盘导航、对话框焦点归还、状态播报和减少动态效果偏好。页面隐藏时停用麦克风，首屏离开视口时停止渲染循环。

## 交付边界

本次交付是可以运行的界面原型。需求回应为预设情境，不代表实际模型推理；麦克风只分析本地音量，不转写、不保存、不上传录音。需求摘要没有提交到服务端。真实模型、CRM、留资接口与企业联系方式沿用技术栈决策，在资料和服务配置落实后接入。

未编造成立时间、办公城市、邮箱、备案号或客户案例。能力文案是按用户给出的业务方向创作的设计稿，正式发布前需要业务核实。
