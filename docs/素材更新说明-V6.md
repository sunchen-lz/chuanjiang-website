# 宣传片素材更新 · V6

本版依据用户提供的企业宣传片补充内容，沿用 V4 已校准的 V1 饱和度与山水动效。

| 之前的空缺 | 本版处理 |
|---|---|
| 品牌故事只有文字 | 接入完整 3 分 41 秒宣传片，首页、关于川江、服务与资料均有入口 |
| 缺少直观的企业介绍素材 | 使用原片画面作为封面，附原生播放器、四个章节入口与文字介绍 |

视频保持原文件内容，未裁剪或重新编码；封面为原片截帧。片中已有中文字幕，另提供文字介绍。关闭弹窗、切换页面、切到后台时暂停；再打开可继续观看。

离线包须完整解压，保留“品牌素材”文件夹。首页不自动播放、不预取完整视频；点击观看后播放。
