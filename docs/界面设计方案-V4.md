# 界面 DEMO V4

本轮按用户澄清执行：回到 V1 的饱和度与色彩密度，不做全站降饱和。以 V1 实际页面的深青墨底、水青亮部、暖金按钮和浅米文字为基准，内页由同一色阶衍生。

- 全站取消残留的蓝、紫与橄榄绿配色，统一标题、产品卡、工作台、反馈状态、表单、页脚和悬停反馈。
- 真实 LOGO 去除白底，降低饱和度与对比，保持标志形态。导航与页脚同步处理。
- 水纹由底部约两成区域扩展到首屏下半部。连续线流与细长水光粒子共享波场；无需声音持续运动。
- 山体通过较亮远山与更深近山形成层次，柔化墨边，增加山势可见度，不添加轮廓描边。
- 提升移动端部分正文、表单和功能标签的字号，统一输入边界、焦点和状态反馈。

保留既有十个页面及技术功能入口，实际界面体验包同步调整配色。真实 AI、数据库、CMS、CRM、访问采集、登录与正式软件等仍按原架构实施，不将本地 DEMO 功能描述为生产服务。

客户交付包括离线 HTML、独立下载体验包、设计思路 HTML/PDF、技术功能入口对照与截图。V1、V2、V3 保留。
